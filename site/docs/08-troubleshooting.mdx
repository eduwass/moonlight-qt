title: Troubleshooting
description: What has gone wrong before, and what fixed it.
---

## "Failed to initialize video capture/encoding. Is a display connected and turned on?"

The host's displays are asleep. Wake them before connecting; see [Hosts](/hosts) for a **Before connecting** command for each kind of machine.

## The picture is black

The host's screen is asleep or blanked. On a Mac, wake it as above. On Hyprland, turn the output on (DPMS); `pc-wake` from [Hosts](/hosts) does it.

## The lock screen is all I get

The host's session is locked. Type its password through the stream, or unlock it in the **Before connecting** command (on Linux, `loginctl unlock-sessions`).

## Colours look washed out

Turn on **Raw colours** for that device. macOS fits a stream's colours to your display; a desktop that was tuned by eye on a wide-gamut monitor then looks duller than on its own cable.

## Two pointers

**Instant pointer** is on for a host that cannot leave its cursor out of the picture. Turn it off for that device. (With a Mac host the app waits for the host's cursor helper before it shows your pointer, so a helper that cannot get through gives you the host's cursor alone, one round trip behind; on the host, look for a prompt asking whether "sunshine" may find devices on the local network, and allow it, or switch it on under System Settings > Privacy & Security > Local Network. Or give the device an ssh destination in its **Clipboard** field: the cursor then comes over ssh, which macOS does not ask about.)

## It is slower than it was

Open the bar and rest on the connection. If it says Wi-Fi or Tailscale where you expected a cable, Moonlight has drifted to another address for the host: it remembers the address a host last reported for itself and tries that one first. Connecting from the device window pins the address each time. If the link is right and still slow, run [the doctor](/settings#doctor).

## The picture is soft

The stream's size does not match the window's pixels. Check that **Follow size** is on, or that a fixed size is what you meant. On a Linux host, check that its output has the stream's size (`hyprctl monitors`): a configuration reload resets a virtual output unless the watcher from [Hosts](/hosts) is running.

## "The stream could not be started"

A stream that the other machine takes and then drops in its first half minute is tried once more by itself, three seconds later, before anything is said: that covers a host that was just restarting, or still ending the stream before. If you see the message after that, the second try failed too. (A machine that could not be reached at all is not tried again: that message comes at once.) Look at whether Sunshine is running on the other machine, then at the ports the message names.

## A warm stream is gone

Its time ran out (Settings › General), the host ended the session, or your Mac slept.

## The watching Mac fell asleep

A Mac with its lid closed needs both a display and power to stay awake. If its monitor is switched off it sleeps, whatever is running.

## Switches for the curious

The device window sets these for you. Starting a stream by hand (`MoonlightNext.app/Contents/MacOS/Moonlight stream <address> Desktop ...`), they are environment variables:

| Variable | Does |
| --- | --- |
| `MOONLIGHT_CHROME` | The window with the bar and no title bar. `linux` gives the Linux mark. |
| `MOONLIGHT_WINDOW=WxH` | The window to open, in points. |
| `MOONLIGHT_WINDOW_AT=left,top` | Where to open it: its left edge and its top, in points from the main screen's bottom left. Ignored if that is on no screen. |
| `MOONLIGHT_WINDOW_ONCE=1` | The window's size is for this stream only: where it is left is remembered, how large is not. A link's `size=` sets it. |
| `MOONLIGHT_FOLLOW=0` | Start with Follow size off. |
| `MOONLIGHT_PANEL_PIXELS` | Start with True Pixels on. |
| `MOONLIGHT_RAW_COLOR` | Raw colours. |
| `MOONLIGHT_NO_SOUND` | No sound: the stream opens no sound output. |
| `MOONLIGHT_QML=1` | Start a device's stream through Moonlight's own screens, as it was before: half a second slower, and with their error dialogs. (A stream started by hand, with no `MOONLIGHT_DEVICE`, goes that way anyway.) |
| `MOONLIGHT_OPEN_URL` | Not for you: how a link that reached a stream's process is handed to a newly started device window. |
| `MOONLIGHT_CLIPBOARD=me@host` | Share the clipboard with that ssh destination. |
| `MOONLIGHT_LOCAL_CURSOR` | Instant pointer. |
| `MOONLIGHT_POINTER` | Not read by the app: set to 1 or 0 for a device's **Before connecting** command, to say whether Instant pointer is on. |
| `MOONLIGHT_FPS_ABOVE=pixels:above:below` | The frame rate by stream size, at every restart: `above` for a stream of more than `pixels`, `below` otherwise. The first start has what `--fps` says. |
| `MOONLIGHT_CLASSIC` | Moonlight's own screens instead of the device window. |
