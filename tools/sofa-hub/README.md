# sofa-hub

The sofa keyboard drives the Apple TV, until omarchypc's desktop is streamed to it. Then the keyboard
and trackpad belong to the desktop. Runs on omarchypc as a systemd user service.

- **On the Apple TV:** arrows move, Enter selects, Esc/Backspace go back, ⌘H or F3 go home,
  Space or the play key play or pause, the volume keys change the TV's volume. The trackpad is held
  and does nothing.
- **Streaming omarchypc:** the hub follows `CLIENT CONNECTED` / `CLIENT DISCONNECTED` in Sunshine's
  log and lets go of both devices for the stream.
- **In a stream:** the desktop gets a copy of the trackpad with palms filtered out touch by touch
  (`palm.ts`): a touch that lands within 0.3 s of a key, or grows palm-sized, is dropped until lifted.
- **By hand:** Caps+Esc, or `bun hub.ts mode tv|desktop|toggle`.

## Install on omarchypc

```sh
dir=~/.local/share/sofa-hub
mkdir -p $dir && cp *.ts $dir/
git clone https://github.com/JarekToro/bunatv.git $dir/bunatv   # Apple TV Companion protocol; alpha, unlicensed
(cd $dir/bunatv && git checkout b3842e3 && bun install --ignore-scripts)
sudo install -m644 70-sofa-hub.rules /etc/udev/rules.d/ && sudo udevadm control --reload && sudo udevadm trigger -s input
cp sofa-hub.service ~/.config/systemd/user/ && systemctl --user enable --now sofa-hub
```

Pair once with the Apple TV: `bun hub.ts pair` and type the PIN it shows. Credentials go to
`~/.config/bunatv.json`.

## The rest of omarchypc's sofa setup

Set up by hand on 2026-11-23, outside this folder:

- **Bluetooth:** a HOMMIE dongle (RTL8761B) on a USB extension outside the cabinet. The internal Intel
  7260 is off (`/etc/udev/rules.d/81-disable-internal-bt.rules`), the dongle never autosuspends
  (`/etc/modprobe.d/btusb-no-autosuspend.conf`), and Wi-Fi is off (the PC is wired).
- **Keyboard:** `/etc/modprobe.d/hid_apple.conf` sets `fnmode=1`: media keys first, Fn for F1–F12.
- **Palms:** `/etc/libinput/local-overrides.quirks` lowers the palm size threshold to 600.
- **Hyprland** (`~/.config/hypr/input.lua`): 3- and 4-finger workspace swipes that step into empty
  workspaces, and macOS pointer and scroll curves for the trackpad copy, generated by
  `T=0.875 PTS=1 bun curve.ts`. `~/.config/hypr/t3space.lua` loads Omarchy's media keys too.
